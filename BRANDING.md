# Bike Weather Branding

## Repository assets

| Asset | Dimensions | Use |
| --- | ---: | --- |
| custom_components/bike_weather/brand/icon.png | 512 × 512 RGBA | local Home Assistant integration icon |
| assets/branding/readme-banner.png | 1280 × 320 RGB | German README banner |

| assets/branding/readme-background.png | generated source | banner source without title |
| assets/branding/social-background.png | generated source | social-preview source without title |

The illustrations were generated for this repository with OpenAI image
generation during Phase 7 and then resized/composed for the target
dimensions. No third-party brand logos or copied marks are used. These are
repository assets, not official Home Assistant brand assets.

## Home Assistant Brands

The local icon is suitable for the repository and local HA 2026.3+ branding
path. It must not be described as an officially published asset in the
Home Assistant Brands repository. An official Brands pull request, if desired,
is a separate future task and is not part of Beta 3.
