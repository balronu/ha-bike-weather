# Bike Weather v0.1.0-beta.3

## Deutsch

### Enthalten

- verbesserter Config Flow mit nativen EntitySelectoren;
- eindeutige Vorauswahl lokaler Temperatur-, Wind- und Regenratensensoren;
- Einheiten-Normalisierung ohne stille Nullwerte;
- lokalisierte Provider- und Options-Flow-Beschriftungen;
- responsive Lovelace-Karte mit Karteneditor, Datenqualität und Cache-Version;
- neues Logo, README-Banner, Social Preview und vollständige Dokumentation;
- Regressionstests für Beta-2-Kompatibilität und HACS-Paketinhalt.

### Einschränkungen

Dies ist eine Beta, keine Stable-Freigabe. Produktive HA-Installation,
HACS-Update, Dashboard-Änderung und echter Praxistest sind nicht enthalten.
Echte Home-Assistant-Screenshots wurden nicht behauptet oder simuliert.

## English

### Included

- native EntitySelectors in the config flow;
- unambiguous local temperature, wind and rain-rate suggestions;
- unit normalization without silently inventing zero values;
- localized provider and options labels;
- responsive Lovelace card with editor, data quality and cache versioning;
- new logo, README banner, social preview and complete documentation;
- regression contracts for Beta-2 compatibility and HACS package content.

### Limitations

This is a beta, not a stable release. No productive HA installation, HACS
update, dashboard change or real-world runtime test is included. No real
Home Assistant screenshots were fabricated.
