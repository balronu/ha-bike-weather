# Installation (Entwurf)

Für diese lokale Beta ist noch keine Installation freigegeben. Nach Freigabe
wird das Repository als HACS-Custom-Repository eingebunden, die Integration
über **Einstellungen → Geräte & Dienste → Integration hinzufügen** eingerichtet
und anschließend die Karte mit der `entry_id` konfiguriert.

Die bestehende YAML-/REST-Lösung bleibt bis zum ausdrücklich freigegebenen
Hot-Cutover unverändert. Es gibt keinen automatischen Import und keine
Übernahme bestehender Entity-IDs.
