# Bike Weather v0.1.0-beta.1

## Status

This is a pre-release for controlled first practical testing. Offline tests and
standalone Chromium card checks pass. Full Home Assistant runtime, Hassfest and
HACS validation were not available in the local environment and remain open
limitations.

## Included

- `bike_weather` config flow and options flow;
- coordinator-backed assessment and forecast sensors;
- Home Assistant and OpenWeatherMap source handling with fallback behavior;
- authenticated `bike_weather/card_data` WebSocket command;
- automatic Lovelace card resource registration;
- `custom:bike-weather-card` with editor and forecast display.

## Important

The beta has not been installed on VM 104. The legacy YAML/REST bicycle-weather
components remain unchanged. Use a backup and a controlled maintenance window
before any future migration.
