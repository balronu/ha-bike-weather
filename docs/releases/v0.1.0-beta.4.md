# Bike Weather v0.1.0-beta.4

## Deutsch

### Enthalten

- Options-Flow-Fix für die schreibgeschützte `config_entry`-Property in Home
  Assistant 2026.10;
- Regressionstest für den ursprünglichen `AttributeError`;
- Rückwärtskompatibilität für bestehende Beta-2- und Beta-3-Einträge,
  einschließlich leerer Optionswerte;
- unveränderte Wetterquellen, lokale Sensoren, Entity-IDs und Dashboard-
  Verträge.

### Einschränkungen

Dies ist eine Beta, keine Stable-Freigabe. Die Installation und der
Praxistest in der produktiven Home-Assistant-Instanz erfolgen ausschließlich
durch den Nutzer. Es wurden keine Config Entries, Dashboards, HACS-
Installationen oder Home-Assistant-Prozesse verändert.

## English

### Included

- Options Flow compatibility fix for Home Assistant 2026.10's read-only
  `config_entry` property;
- regression coverage for the original `AttributeError`;
- backward compatibility for existing Beta 2 and Beta 3 entries, including
  empty options;
- unchanged weather sources, local sensors, entity IDs and dashboard
  contracts.

### Limitations

This is a beta, not a stable release. Installation and practical testing in
the productive Home Assistant instance are performed only by the user. No
config entries, dashboards, HACS installations or Home Assistant processes
were changed.
