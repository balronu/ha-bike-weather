# Bike Weather v0.1.0-beta.2

## Fixes

- Bundle the runtime core inside `custom_components/bike_weather/` so the
  coordinator imports only files delivered by the HACS integration package.
- Keep the existing Config Flow contract while preventing the Beta 1
  `No module named 'bike_weather_core'` packaging failure.
- Add a regression contract test that verifies the bundled core and relative
  runtime import.

## Scope

This is a packaging/config-flow hotfix. It contains no new scoring features,
graphics, dashboard changes, or productive Home Assistant changes.

The release has not been installed or restarted on the productive Home
Assistant VM. A productive HA runtime validation remains an explicit
limitation of this beta.
