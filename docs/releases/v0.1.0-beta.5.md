# Bike Weather v0.1.0-beta.5

## Deutsch

### Enthalten

- Korrektur des HA-2026.10-Options-Flows: `self.hass` wird für Sprache und
  Sensorvorschläge verwendet; `ConfigEntry.hass` wird nicht mehr gelesen;
- realitätsnahe Regressionstests für bestehende Einträge mit `options={}`;
- eindeutige GW1100A-kompatible lokale Sensoren werden im Options-Flow
  vorausgefüllt, während gespeicherte Werte Vorrang behalten;
- Speichern und erneutes Öffnen des Options-Flows bewahren die Einstellungen;
- unveränderte Config-Entry-Identität, Entity-IDs, Wetterquellen und
  Dashboard-Verträge.

### Einschränkungen

Dies ist eine Beta, keine Stable-Freigabe. Die lokale Testumgebung enthält
keine vollständige Home-Assistant-Fixture; der Lauf testet die echte Flow-Datei
mit einem kleinen HA-API-kompatiblen Harness. Der vollständige Python-/Hassfest-
/HACS-/Gitleaks-Gate läuft auf GitHub Actions. Installation, Neustart und
Praxistest in der produktiven VM 104 erfolgen ausschließlich durch den Nutzer.

## English

### Included

- fixed Home Assistant 2026.10 Options Flow access: language and sensor
  suggestions use `self.hass`, and `ConfigEntry.hass` is never read;
- behavioral regression coverage for existing entries with `options={}`;
- unambiguous GW1100A-compatible local sensors are suggested in the Options
  Flow while stored values retain precedence;
- saving and reopening the Options Flow preserve the settings;
- unchanged config-entry identity, entity IDs, weather sources and dashboard
  contracts.

### Limitations

This is a beta, not a stable release. The local environment has no complete
Home Assistant fixture; the real flow module is exercised with a small
HA-API-compatible harness. The full Python/Hassfest/HACS/Gitleaks gate runs in
GitHub Actions. Installation, restart and practical testing on productive VM
104 are performed only by the user.
